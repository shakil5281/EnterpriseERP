# AccountsService

Enterprise AccountsService for a multi-company garments/textile ERP, built with .NET 10 Web API, SQL Server 2022, EF Core Code First, Clean Architecture, CQRS/MediatR, repository/unit of work, FluentValidation, AutoMapper, JWT authorization, RabbitMQ integration events, Redis cache, Swagger, and API versioning under `/api/v1`.

```text
AccountsService
|-- AccountsService.API
|-- AccountsService.Application
|-- AccountsService.Contracts
|-- AccountsService.Domain
|-- AccountsService.Infrastructure
`-- AccountsService.Tests
```

## Core Rules

- All business tables carry `CompanyId`.
- Chart of account code and voucher number are unique per company.
- Vouchers need at least two lines.
- Debit and credit must match before save/post.
- Posted vouchers create immutable `GeneralLedgerEntries`.
- Posted vouchers cannot be edited or cancelled.
- Closed accounting periods reject transactions.
- Approval/post/cancel workflows write audit logs.
- Multi-company transfer creates two vouchers.
- Advance salary payment publishes `AdvanceSalaryPaid`.
