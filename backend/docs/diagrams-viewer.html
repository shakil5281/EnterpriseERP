2. Data flow (punch → payroll)

sequenceDiagram

    participant PD as PunchDataService
    participant ATT as AttendanceService
    participant SH as ShiftService
    participant HR as HRService
    participant PR as PayrollService
    participant UI as hrhub
    Device->>PD: Raw punch log
    PD->>PD: PunchRecord
    UI->>ATT: Process daily attendance
    ATT->>HR: Employees
    ATT->>PD: Punches
    ATT->>SH: Shift evaluation
    SH-->>ATT: ShiftEvaluationDto
    ATT->>ATT: DailyAttendance
    UI->>PR: Monthly payroll
    PR->>ATT: Approved summary
    PR->>PR: EmployeePayroll

3. ERD (core entities)

erDiagram
    Company ||--o{ Employee : employs
    Company ||--o{ Shift : defines
    Shift ||--|| ShiftRule : has
    Employee ||--o{ EmployeeShiftAssignment : roster
    Employee ||--o{ DailyAttendance : daily
    Employee ||--o{ EmployeePayroll : monthly
    PunchRecord }o--|| Employee : punchNumber
    Company {
        guid Id PK
        string CompanyNameEn
    }
    Employee {
        guid Id PK
        int PunchNumber
        string EmployeeID
    }
    DailyAttendance {
        guid Id PK
        date AttendanceDate
        int OvertimeMinutes
        bool IsApproved
    }
    EmployeePayroll {
        guid Id PK
        decimal NetSalary
    }

4. Shift selection

flowchart TD
    A[Date + Employee] --> B{Temporary shift?}
    B -->|Yes| T[TemporaryAssignment]
    B -->|No| C{Roster current?}
    C -->|Yes| R[EmployeeShiftAssignment]
    C -->|No| G[Default shift]
    T & R & G --> E[ShiftEvaluationService]
    E --> OUT[ShiftEvaluationDto]

5. Daily attendance

flowchart LR
    A[Process day] --> B[HR employees]
    B --> C[PunchData punches]
    C --> D[Shift evaluation]
    D --> E[AttendanceProcessingService]
    E --> F[DailyAttendance]
    F --> G[Approve]
    G --> H[Payroll monthly summary]

6. Salary calculation

flowchart TB
    POL[Payroll policy] --> CALC[PayrollCalculationService]
    SAL[Employee salary] --> CALC
    ATT[Approved attendance] --> CALC
    CALC --> MODE{Monthly / Daily / Hourly}
    MODE --> OT[Overtime]
    OT --> NET[Net salary]
    NET --> EP[EmployeePayroll]
